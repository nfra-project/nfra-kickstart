# Arbeitsanweisung

Die Aufgabe besteht darin, ausschließlich `dist/kickstart.sh` zu bearbeiten.

Bevor irgendeine Änderung an `dist/kickstart.sh` vorgenommen wird, muss die vollständige geplante Änderung dem User präsentiert werden. Die Präsentation muss den kompletten resultierenden Diff enthalten. Erst nachdem der User diese Änderung ausdrücklich bestätigt hat, darf `dist/kickstart.sh` editiert werden.

Ohne ausdrückliche Bestätigung dürfen keine Änderungen an `dist/kickstart.sh` vorgenommen werden.
